Джарвис это голосовой ассистент для управления пк работающий без интернета.Он откликается только тогда когда вы говорите его имя(Джарвис) и команда.
Инструкция:Скачайте, перетащите на рабочий стол, запустите.
Примечание:иногда при запуске может ругаться антивирус. Просто нажмите выполнить в любом случае.
Команды:Джарвис запусти стим,кс,брузер.Джарвис закрой стим, кс, браузер. Джарвис усни(он не будет слушать и не будет ничего делать до тех пор пока не услышит команду Дарвис просыпайся).Джарвис выключи пк
